# 📚 북튜닝(Book Tuning) v4.3 노션 템플릿 가이드 & 웹앱 연동 매뉴얼

> 💡 **환영합니다!**  
> 본 템플릿은 구글 스프레드시트 없이 **노션 단독 백엔드**로 동작하는 풀스택 독서 웹앱 **'북튜닝 v4.3'**의 공식 데이터베이스 패키지입니다.  
> 노션 자체에서도 훌륭한 독서 기록 대시보드로 활용할 수 있으며, 배포된 웹앱과 연동하면 **스마트 도서 검색**, **카메라 사진 OCR 문장 추출**, **Gemini AI 1인칭 감상문 생성** 기능까지 누리실 수 있습니다.

## 1. 4대 핵심 데이터베이스(DB) 활용법

본 템플릿은 4개의 표(데이터베이스)가 유기적으로 관계형(Relation) 연결되어 있습니다.

### 📖 1) 도서 DB
- **역할**: 내가 읽고 있거나 완독한 모든 책의 마스터 목록입니다.
- **주요 활용법**:
  - 새 페이지를 만들고 `*책 제목`을 입력합니다. (웹앱을 이용하면 검색 한 번으로 표지와 페이지수가 자동 입력됩니다.)
  - `*전체 페이지수`를 숫자로 입력하면 독서일지에 기록된 누적 쪽수를 바탕으로 **완독률(진도율 %)**이 실시간 자동 계산됩니다.
  - `표지`에 이미지 파일이나 링크를 넣으면 **'갤러리(책장)'** 보기에서 실제 서재처럼 시각적으로 책을 관리할 수 있습니다.
  - 웹앱에서 작성한 **'나의 독서 감상문'**과 **'Gemini AI 감상문'**은 해당 도서 페이지 본문 내부에 예쁜 콜아웃 블록으로 영구 보존됩니다.

### 📅 2) 독서일지 DB
- **역할**: 매일매일 읽은 페이지 수와 간단한 생각을 기록하는 진도 로그입니다.
- **주요 활용법**:
  - 도서 DB 페이지 내부의 `독서일지` 관계형 항목에서 `+ 새로 만들기`를 누르는 것이 가장 편리합니다. (관련 책이 자동으로 매핑됩니다.)
  - 독서일지 DB에서 직접 작성할 경우 `관련 책` 항목에서 해당하는 도서를 꼭 선택해 주세요.
  - **`이번에 읽은 페이지(숫자)`**: 그날까지 읽은 **누적 페이지 번호**를 입력합니다.
  - **`독서 감상록`**: 오늘 분량을 읽고 떠오른 생각, 느낀 점을 적습니다. 내용이 길면 페이지 본문 안에 자유롭게 작성하셔도 좋습니다.

### 💡 3) 문장수집 DB (인사이트)
- **역할**: 책을 읽다가 마음에 와닿은 구절, 기억하고 싶은 핵심 문장들을 아카이빙하는 공간입니다.
- **주요 활용법**:
  - `내용`에 인상 깊은 문장을 기록하고, `페이지`에 쪽수를 남깁니다.
  - `관련 책`을 연결하면 도서 DB 상세 페이지에서도 해당 책에서 발췌한 모든 문장을 한눈에 모아볼 수 있습니다.
  - 웹앱의 **[문장 수집]** 기능을 이용하면 스마트폰 카메라로 책 페이지를 찍어 올리기만 해도 **Gemini OCR이 문장을 자동으로 인식해 텍스트와 사진 블록으로 노션에 동시 기록**해 줍니다.

### 👤 4) 사용자 DB
- **역할**: 독서 모임이나 가족, 동료들이 하나의 노션 공간을 함께 쓸 때 **개인별 독서 기록을 분리하고 동명이인을 방지**하는 프로필 관리 DB입니다.
- **주요 활용법**:
  - `닉네임`: 활동할 이름 (예: 조용희, 책벌레 등)
  - `PIN`: 본인 확인용 4자리 비밀번호 (예: 7719)
  - 웹앱에서는 본인이 등록한 도서에 대해서만 진도 기록·문장 수집·도서 수정/삭제가 가능하며, 타인의 도서는 열람 및 공감(❤️)만 가능한 읽기 전용으로 안전하게 보호됩니다.

## 2. 노션 API 통합(키) 발급 & 권한 연결 (3분 완성)

웹앱과 노션이 실시간으로 대화할 수 있도록 노션 API 키를 발급받아 연결합니다.

### 1단계: API 통합(Integration) 생성 및 Secret 토큰 발급
1. [노션 개발자 페이지 (My Integrations)](https://www.notion.so/my-integrations)에 접속하여 로그인합니다.
2. **`+ 새 API 통합 만들기(Create new integration)`** 버튼을 클릭합니다.
3. 기본 정보 입력:
   - **이름**: 알아보기 쉬운 이름 입력 (예: `북튜닝 연동 봇`)
   - **연결된 워크스페이스**: 본인이 템플릿을 복제한 워크스페이스 선택
4. 맨 아래 **[저장 (Submit)]**을 누릅니다.
5. 생성된 화면의 '시크릿(Secrets)' 탭에서 **[보기(Show)]** ➔ **[복사(Copy)]**를 클릭해 **내부 통합 토큰(`ntn_...`)**을 안전한 곳에 메모해 둡니다. (이 토큰이 바로 `NOTION_API_KEY` 입니다.)

### 2단계: 최상위 노션 페이지에 연결(Connections) 추가
> ⚠️ **중요**: 토큰만 만들었다고 연결되는 것이 아니라, 노션 페이지에 봇을 초대해야 읽기/쓰기 권한이 생깁니다!

1. 복제하신 최상위 페이지(**`📚 북튜닝(Book Tuning) 개인 독서 기록장`**)로 이동합니다.
2. 페이지 우측 상단의 **`···` (점 3개 더보기)** 메뉴를 클릭합니다.
3. 메뉴 맨 아래쪽의 **[연결 추가 (Add connections)]**를 클릭합니다.
4. 방금 1단계에서 만든 API 통합 이름(예: `북튜닝 연동 봇`)을 검색하여 선택하고 연결을 승인합니다.
5. **끝!** 최상위 페이지에 한 번만 연결하면, 안에 포함된 도서 DB, 독서일지 DB, 문장수집 DB, 사용자 DB까지 **모든 하위 DB에 권한이 자동 상속**됩니다.

## 3. 노션 DB 아이디(ID) 확인 & 웹앱 연동

웹앱(Vercel 배포 환경 또는 로컬 `.env.local`)에 각 데이터베이스의 32자리 고유 ID를 전달해주어야 합니다.

### 🔍 32자리 DB ID 찾는 방법
1. 복제한 페이지 내의 각 데이터베이스(표) 제목 우측 `···` ➔ **[링크 복사]**를 클릭하거나, 해당 DB를 전체 페이지로 엽니다.
2. 복사된 URL 주소창을 확인합니다:
   ```text
   https://www.notion.so/myworkspace/33f9a4211895829a9cdf017dc886e012?v=08a...
   ```
3. 주소의 `notion.so/` (또는 워크스페이스명/) 뒤부터 `?v=` 직전까지의 **32자리 영문/숫자 문자열**이 바로 그 데이터베이스의 ID입니다!

### 📋 웹앱 환경변수(Vercel / .env.local) 매핑 표
| Vercel 환경변수 Key | 연결할 노션 DB / 키 설명 |
| :--- | :--- |
| `NOTION_API_KEY` | 1단계에서 복사한 노션 내부 통합 Secret 토큰 (`ntn_...`) |
| `NOTION_BOOK_DB_ID` | **도서 DB**의 32자리 ID |
| `NOTION_LOG_DB_ID` | **독서일지 DB**의 32자리 ID |
| `NOTION_INSIGHT_DB_ID` | **문장수집 DB**의 32자리 ID |
| `NOTION_USER_DB_ID` | **사용자 DB**의 32자리 ID |
| `GEMINI_API_KEY` | Google AI Studio 무료 발급 키 (AI 감상문 & 이미지 OCR용) |
| `KAKAO_REST_API_KEY` | 카카오 Developers 발급 키 (도서 검색용) |

> 💡 **원클릭 팁**: Vercel 프로젝트 대시보드의 `Settings` ➔ `Environment Variables`에서 위의 키=값을 한 번에 붙여넣기 하면 자동으로 모든 필드가 채워집니다.

## 4. 웹앱과 노션의 실시간 동기화 동작 원리

- **실시간 수정(PUT)**: 웹앱에서 도서의 제목, 표지, 페이지수, 소개글을 수정하면 노션 페이지의 속성들이 즉시 실시간 동기화됩니다.
- **완전 삭제(DELETE)**: 웹앱에서 도서를 삭제하면 노션 공식 API(`archived: true`)를 호출하여 **노션 DB 표에서 즉시 사라지고 노션 워크스페이스의 [휴지통(Trash)]으로 안전하게 이동**합니다.
- **종속 기록 일괄 정리**: 웹앱에서 도서 삭제 시, 노션에 연결되어 있던 모든 독서일지와 문장수집 기록들까지 노션에서 함께 추적하여 휴지통으로 일괄 아카이브되므로 DB에 찌꺼기 기록이 남지 않습니다.

## 5. 템플릿 커스텀 및 수식 팁

1. **`*` 표시 속성 보존**:
   - `*책 제목`, `*전체 페이지수` 등 이름 앞에 `*`가 붙어 있는 속성은 웹앱 백엔드 코드가 직접 인식하는 필수 속성입니다. 속성 이름을 바꾸거나 삭제하지 마세요.
2. **숨김 처리된 수식 활용**:
   - 템플릿에는 시행착오를 거치며 정교화된 완독률 계산 수식들이 포함되어 있습니다. 필요에 따라 속성 숨김을 해제하여 확인하실 수 있습니다.
3. **AI를 활용한 수식 확장**:
   - 노션 AI나 Gemini, ChatGPT에게 수식 내용을 복사해 붙여넣고 *"이 수식을 바탕으로 이번 달 읽은 분량만 따로 필터링하는 수식을 짜줘"*라고 요청하면 손쉽게 나만의 맞춤형 수식으로 확장할 수 있습니다.
4. **출처 표기 및 저작권**:
   - 본 템플릿과 연동 웹앱은 **기록조율사 서울외고 조용희 선생님**의 기획 및 설계로 제작되었습니다. 개인 및 교육용으로 자유롭게 커스텀하여 즐거운 독서 여정을 만들어 보세요!
