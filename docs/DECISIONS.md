# DECISIONS

- 2026-10-21 · 아키텍처 전환 (GAS+구글시트 ➔ Next.js+Notion 단독 백엔드) · 중간 구글 시트를 완전히 제거하고 기존 3개 노션 DB(도서/일지/문장)를 직접 조회·수정하는 단독 백엔드로 전환하기로 결정.
- 2026-10-21 · 사용자 DB(User DB) 신설 및 관계형 연결 · 동명이인 식별(닉네임+4자리 PIN)을 보장하고, 노션 자체를 개인별 독서 포트폴리오 웹앱 뷰로 활용할 수 있도록 '사용자 DB'를 추가하고 도서/일지/문장에 관계형(Relation)으로 묶기로 결정.
- 2026-10-21 · API 키 보안 강화 조치 · .env.example 내 실제 키를 즉시 마스킹하고 .env.local로 격리, .gitignore를 신설하여 깃허브 오픈소스 배포 시 API 키가 원천적으로 노출되지 않도록 조치 완료.
- 2026-10-21 · 국립중앙도서관(NL) 쪽수 자동 파싱 및 Gemini OCR 복원 · 카카오 검색 시 누락되는 총 페이지수를 국립중앙도서관 API에서 실시간 파싱하고, 이미지 첨부 시 Gemini 2.5 Flash를 이용한 OCR 텍스트 자동 추출 파이프라인 완비.
- 2026-10-21 · 북튜닝 v4.3 고도화 및 편의성 극대화 · 푸터 '노션 DB 열기' 링크 복원, 도서 검색 3대 엔진(카카오, 알라딘, 네이버) 설정 메뉴 복원, 파비콘/PWA 매니페스트/앱 로고 탑재 및 모바일 반응형(화면 틀어짐 방지)을 전면 적용하기로 결정.
- 2026-10-21 · 기존 4인 사용자 실데이터 100% 관계형 이관 완료 · 실제 노션 DB 4종(도서 23권, 일지 43건, 문장 19건)을 기존 4인(조용희, 최정윤, 김진수, 오태훈) 사용자 페이지에 Relation으로 영구 연결 완료.
- 2026-10-21 · 도서 등록 및 알라딘 검색 UX 개선 · 알라딘 검색 시 ItemSearch와 ItemLookUp을 병렬 조합하여 쪽수 누락을 해결하고, 검색 결과 선택 시 바로 저장되는 대신 도서 정보(쪽수, 표지, 출처 등)를 사용자가 검토·수정 후 등록할 수 있는 확인 폼 단계를 복원하기로 결정.
- 2026-10-21 · 개인정보 및 PIN 입력 보안 정비 · 로그인 폼에서 하드코딩된 특정 사용자 닉네임 예시와 '0000' 기본값을 전면 삭제하고, 사용자가 노션에 등록한 PIN을 직접 입력하도록 수정. 푸터 노션 링크를 서울외고 독서 모임 지정 페이지로 변경.
- 2026-10-22 · 도서 소유권 분리 보안 및 실시간 노션 삭제/동기화 보장 · 자신이 등록한 책에 대해서만 진도 기록, 문장 수집, 도서 수정/삭제, 감상문 작성을 허용하고 타인 도서는 열람 및 공감(❤️)만 가능한 읽기 전용으로 UI와 4개 백엔드 API에 소유자 검증 가드를 전면 도입. 또한 웹앱의 도서 삭제 시 노션에서도 즉시 `archived: true`로 휴지통에 이동하며 연관 일지/문장까지 종속 삭제 처리되도록 결정.
